# Checklist: Review Bài Viết

> Dùng trước khi publish bài mới và khi review lại bài cũ.

---

## Kiểm tra nội dung

| # | Mục | ✅/❌ | Ghi chú |
|---|-----|------|---------|
| C1 | H1 là câu hỏi hoặc giải pháp cụ thể (không phải tiêu đề chung chung) | | |
| C2 | Answer-first trong 3 câu đầu tiên dưới H1 | | |
| C3 | Đoạn answer-first tự chứa nghĩa (đọc tách khỏi bài vẫn hiểu) | | |
| C4 | Mỗi H2 là câu hỏi đúng như khách hỏi | | |
| C5 | Mỗi H2 có câu trả lời ngay bên dưới (không viết H2 rồi đi giới thiệu) | | |
| C6 | Mỗi đoạn tự chứa ngữ cảnh (không có "như đã nói ở trên") | | |
| C7 | Một ý — một chỗ (không rải câu trả lời cho 1 câu hỏi ra nhiều đoạn) | | |
| C8 | Có ít nhất 1 yếu tố AI khó bịa (data, case study, quy trình thật) | | |
| C9 | Số liệu cụ thể (không phải "nhiều", "nhanh", "tốt") | | |
| C10 | FAQ section nếu có câu hỏi thêm — Q/A rõ ràng, tự chứa | | |

---

## Kiểm tra SEO kỹ thuật

| # | Mục | ✅/❌ | Ghi chú |
|---|-----|------|---------|
| S1 | Title tag ≤ 60 ký tự, chứa từ khóa chính | | |
| S2 | Meta description ≤ 155 ký tự, answer-first, có CTA nhẹ | | |
| S3 | URL slug ngắn gọn, chứa từ khóa chính | | |
| S4 | Ảnh có alt text mô tả chính xác | | |
| S5 | Ảnh chính (OG image) đã đặt | | |
| S6 | Schema phù hợp (Article, FAQPage, HowTo) đã thêm | | |
| S7 | Schema validate qua Rich Results Test — không có lỗi đỏ | | |
| S8 | Breadcrumb có và đúng | | |

---

## Kiểm tra internal linking

| # | Mục | ✅/❌ | Ghi chú |
|---|-----|------|---------|
| L1 | Link tới trang trụ cột của cụm | | |
| L2 | Link tới 2–3 trang con liên quan trong cụm | | |
| L3 | Anchor text mô tả đúng chủ đề (không phải "xem thêm", "click here") | | |
| L4 | Bài này được link từ ít nhất 1 trang khác trong site | | |
| L5 | Không có orphan page (bài này có ít nhất 1 link trỏ vào) | | |

---

## Kiểm tra tác giả & E-E-A-T

| # | Mục | ✅/❌ | Ghi chú |
|---|-----|------|---------|
| A1 | Tên tác giả thật (không phải "Admin" hay "Team ABC") | | |
| A2 | Link tới trang tác giả | | |
| A3 | Ngày publish chính xác | | |
| A4 | Ngày cập nhật hiển thị (nếu đây là bài cập nhật) | | |
| A5 | Nội dung được review bởi người có chuyên môn thật | | |

---

## Kiểm tra trước publish

| # | Mục | ✅/❌ |
|---|-----|------|
| P1 | Đọc lại toàn bài — logic mạch lạc | |
| P2 | Không có lỗi chính tả / ngữ pháp rõ ràng | |
| P3 | Ảnh load đúng, không broken | |
| P4 | CTA cuối bài có và phù hợp | |
| P5 | Mobile view xem thử — đọc được | |
| P6 | Schema validate lần cuối | |
| P7 | Sau publish: Submit URL Inspection → Request Indexing | |
